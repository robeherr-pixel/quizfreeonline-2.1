# QuizFreeOnline 2.0

Versión profesional independiente basada en la versión online compatible con Render + PostgreSQL.

## Mejoras 2.0
- Interfaz profesional y responsive.
- QR para participantes.
- Contador de participantes conectados.
- Navegación anterior/siguiente.
- Modo pantalla completa.
- Resultados con porcentajes en vivo.
- Exportación CSV y Excel.
- Importación CSV/XLSX.
- Mantiene Socket.IO y PostgreSQL.

## Deploy seguro
Prueba esta versión como un servicio independiente antes de reemplazar producción. Usa la misma estructura de `DATABASE_URL`, pero idealmente una base de datos de prueba durante la validación.
